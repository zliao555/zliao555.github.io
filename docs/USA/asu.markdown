# Arizona State University

Power名校，是1996年起有NSF赞助的[PSERC](https://pserc.asu.edu/overview/)的主导大学。以前以 PS为主，最近几年在大力发展 PE。学校位于凤凰城都会区，周边聚集了台积电、Intel、onsemi、NXP 等众多半导体企业。

---
[Zhou Dong](https://news.engineering.asu.edu/?p=101383&post_type=faculty&preview=1&_ppp=13fede7b63). 小AP，PhD@UTK，Fred Wang的学生，南京航空航天大学校友。在美国ABB研发中心工作四年，担任Principal Scientist。主要研究方向为大功率电力电子变换器，固态变压器，中低压直流系统，固态断路器以及电力电子在电网和AI数据中心中的应用。将于2027年春季入职，目前正在招人。

---
[Zhicheng Guo](https://search.asu.edu/profile/4874621) 小AP，PhD@UT Austin，Alex Huang的学生，东南大学校友。研究方向为固态变压器，中压高频变压器，以及电力电子在电网和能源系统中的应用。其名下实验室为PEEC lab，网站显示招人。

逆变器， 光伏等。

[Mike Ranjram](https://isearch.asu.edu/profile/4008590) 小AP，伊朗裔加拿大人，2021 年 Phd@MIT，Perrault的学生。本科UofToronto，人非常的Nice，学术水平很扎实。他明确表达出希望能招收一些优秀的中国学生，相信新来的学生在他的指导下会有很好的发展。研究生比较出彩的项目是用active switch 来改变transformer turn ratio来实现不同的变比。主要研究方向是比较正统的PE，包括高功率密度转换器，磁性器件研究，Planar Transformer，高频LLC及控制。
